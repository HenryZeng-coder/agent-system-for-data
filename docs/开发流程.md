## Phase 3: GLM-5.1 集成 

### Step 3.1 — GLM 客户端完善

**Prompt:**
```
请完善 /Users/kc/Desktop/E-infoinsight-agent-codes/engine/glm_client.py

当前骨架已有批量调用和验证方法，请实现完整逻辑:

1. batch_rate(companies) — 主入口
   - 从数据库读取 companies(status='scored') + 关联数据
   - 按5家/批分批调用
   - 对每批调用 _call_glm → _parse_response → _validate_result
   - 调用间隔0.5秒
   - 调用 update_database 写入结果

2. _build_batch_prompt(batch) — Prompt构建
   - 读取 engine/prompts/analysis_prompt.md 模板
   - 填入每家企业的: 名称、经营范围、技术岗位占比、技术栈、融资阶段、近期动态、招投标
   - 替换 {companies} 占位符

3. _call_glm(prompt) — API调用
   - POST https://open.bigmodel.cn/api/paas/v4/chat/completions
   - model: GLM-5.1, temperature: 0.1, max_tokens: 500
   - 429: 指数退避 1s→2s→4s→8s (上限60s)
   - 5xx: 重试3次(间隔5s), 全部失败返回None
   - timeout: 30s

4. _parse_response(response) — JSON解析
   - 尝试 json.loads()
   - 失败: temperature→0.05 + 注入few_shot → 重试一次
   - 连续失败: 跳过该批

5. _validate_result(result) — 字段验证
   - score: 0-100整数
   - level: S/A/B/C/D
   - demand_tags: 非空数组
   - sales_pitch: <=50字
   - reasoning: 非空

6. update_database(results) — 写入数据库
   - INSERT INTO ratings (company_id, total_score, rating_level, demand_tags, sales_pitch, reasoning, rated_by='glm')
   - UPDATE companies SET status='rated'
   - 失败的标记 status='retry'

参考: engine/prompts/analysis_prompt.md, engine/prompts/few_shot_examples.json
```

**验收:** 用2家测试企业调用 GLM API，返回合法 JSON (score + level + demand_tags + sales_pitch + reasoning)
